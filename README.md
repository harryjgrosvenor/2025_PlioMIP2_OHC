This repository contains the code and processed netCDFs for the paper American Geophysical Union Geophysical Research Letters Paper: "Simulated changes and future analogy extent of Ocean Heat Content during the mid-Pliocene Warm Period".

Code is provided for all figures in the main and supplemental text.

Note: in some cases (for figure 3, figure S3), code is provided that produces the figure from the paper from unprocessed output from the ESGF database and/or PlioMIP2 databases and providing this data in the repository is too large.
